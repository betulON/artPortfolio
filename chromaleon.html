Chromaleon

Chromaleon was created during a game jam as a collaborative project by a four-person team. My contributions included color direction, 2D illustration, UI work, and programming support.

Contribution

In Chromaleon, I worked across both visual and technical tasks. I contributed to the color palette, 2D illustrations, interface elements, and parts of the implementation. Because game jams require quick decisions, this project taught me how to simplify visuals, communicate with teammates, and finish work under pressure.
